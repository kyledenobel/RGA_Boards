# RGA_Boards
PCB Board design and development for RGA (Recording Guitar Amplifier)

## Issues and Organization
After completing an issue for board design, please mark as resolved and mention your branch/merge and create another issue for fabrication with the milestone "All Boards Have Been Fabricated" linked to the issue.
Similarly, after fabrication is finished, make an issue for testing with the milestone "All Boards Have Been Tested" linked to the issue.
